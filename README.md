# 🚗 Shelter -- Vehicle Insurance Management System

## 📌 Project Overview

**Shelter -- Vehicle Insurance Management System** is a web-based
application developed for the **IWT (Internet and Web Technologies)
Module -- Year 1 Semester 2** as a group project consisting of five
members.

The system is designed to streamline and digitize vehicle insurance
processes including policy creation, management, and claims handling. It
provides a structured platform for customers, agents, and administrators
to manage insurance operations efficiently and securely.

------------------------------------------------------------------------

## 🎯 Objectives

-   Automate vehicle insurance policy management
-   Reduce manual paperwork and human errors
-   Provide a centralized insurance database system
-   Enable secure customer data handling
-   Improve operational efficiency for insurance agents
-   Allow easy navigation between insurance services

------------------------------------------------------------------------

## 🛠️ Technologies Used

-   **HTML** -- Structure of web pages
-   **CSS** -- Styling and UI design
-   **JavaScript** -- Client-side interactivity
-   **PHP** -- Server-side logic
